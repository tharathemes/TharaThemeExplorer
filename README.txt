=============================================================
  Thara Theme Explorer v2.1.0
  Website: https://tharathemes.com
=============================================================

A modern, lightweight Windows utility to customize File Explorer 
navigation, layout, context menus, fonts, and visuals.

-------------------------------------------------------------
FEATURES
-------------------------------------------------------------
* Explorer Layout: Switch between Windows 7 (Classic command bar),
  Windows 10 (Ribbon), and Windows 11 (Modern bar).
* Context Menu: Instantly restore classic Windows 10 full context
  menu or Windows 11 modern Fluent acrylic menu.
* Navigation Pane: Show or hide Home, Gallery, OneDrive, Libraries,
  Network, Recycle Bin, Control Panel, and User folders. Customize 
  Home and Gallery order (Top / Bottom).
* Visuals: Toggle Mica effect on Explorer windows.
* Typography: Customize Windows system fonts and sizes for menus,
  window titles, icons, and message boxes.
* Shell Integration: Quick "Take Ownership" context menu entry.
* Safe & Clean: Zero background telemetry, automatic Explorer
  recovery, per-monitor DPI crisp rendering.

-------------------------------------------------------------
SYSTEM REQUIREMENTS
-------------------------------------------------------------
* Windows 11 (all versions) or Windows 10 (version 1809+, build 17763+)
* 64-bit (x64) and 32-bit (x86) architecture supported (Universal AnyCPU)
* .NET Framework 4.0 or higher (pre-installed on Windows 10/11)

-------------------------------------------------------------
USAGE
-------------------------------------------------------------
1. Run TharaThemeExplorer.exe.
2. Select your desired layout, navigation folders, or fonts.
3. Click "Apply" or "OK". 
4. If prompted to restart Explorer, click "Yes" to apply changes immediately.

-------------------------------------------------------------
FIRST RUN NOTE
-------------------------------------------------------------
Because this tool is free and distributed directly, Windows 
SmartScreen may show an unrecognized app notification on first launch.
Click "More info" -> "Run anyway".
