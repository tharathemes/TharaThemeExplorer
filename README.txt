=============================================================
  Thara Theme Explorer v2.2.0
  Website: https://tharathemes.com
=============================================================

A modern, lightweight Windows utility to customize File Explorer 
navigation, layout, context menus, fonts, and visuals.

-------------------------------------------------------------
FEATURES
-------------------------------------------------------------
* Explorer Layout: Choose Windows 7-style, Windows 10-style, or
  Windows 11-style layouts on supported Windows 11 builds.
* Context Menu: Instantly restore classic Windows 10 full context
  menu or Windows 11 modern Fluent acrylic menu.
* Navigation Pane: Show or hide Home, Gallery, OneDrive, Libraries,
  Network, Recycle Bin, Control Panel, and User folders. Customize 
  Home and Gallery order (Top / Bottom), and add custom files or folders.
* Visuals: Toggle Mica effect on Explorer windows.
* Typography: Customize Windows system fonts and sizes for menus,
  window titles, icons, and message boxes.
* Shell Integration: Quick "Take Ownership" context menu entry.
* Portable executable with automatic Explorer recovery and
  per-monitor DPI rendering.

-------------------------------------------------------------
SYSTEM REQUIREMENTS
-------------------------------------------------------------
* Windows 10 version 1809 or later (32-bit or 64-bit), or Windows 11 (64-bit)
* .NET Framework 4.0 or higher
* Feature behavior may vary between Windows versions and builds

-------------------------------------------------------------
USAGE
-------------------------------------------------------------
1. Download the executable from https://github.com/tharathemes/TharaThemeExplorer/releases.
2. Run TharaThemeExplorer 2.2.0.exe.
3. Select your desired layout, navigation folders, or fonts.
4. Click "Apply" or "OK".
5. If prompted to restart Explorer, click "Yes" to apply changes immediately.

-------------------------------------------------------------
FIRST RUN NOTE
-------------------------------------------------------------
This executable is not digitally signed. Windows SmartScreen may show
an unrecognized-app notification on first launch.
